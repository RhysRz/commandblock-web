# CommandBlock Remote PC Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add secure, owner-scoped Remote PC sessions to CommandBlock Web and Desktop.

**Architecture:** Supabase provides signaling and access control; a separately packaged Desktop Remote Agent handles local consent and WebRTC; the canonical web UI is the remote controller.

**Tech Stack:** Rust, WebRTC, Supabase Postgres/RLS, static CommandBlock Web, GitHub Actions Windows release packaging.

## Global Constraints

- Only the signed-in owner may request or view a session.
- A remote device must display an explicit allow/deny confirmation for every session.
- Sessions expire after ten minutes and local disconnect always wins.
- Initial connectivity is STUN-only and remains free.
