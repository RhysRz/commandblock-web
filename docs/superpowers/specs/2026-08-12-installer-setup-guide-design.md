# คู่มือการตั้งค่าภายในตัวติดตั้ง

## เป้าหมาย

เมื่อติดตั้ง Commandblock แล้ว ผู้ใช้ต้องมีคู่มือการตั้งค่าที่เปิดอ่านได้ทันทีและปลอดภัย คู่มือนี้อธิบายการตั้งค่าโดยไม่มี API key หรือข้อมูลลับอยู่ภายใน

## ประสบการณ์ของผู้ใช้

1. ตัวติดตั้งคัดลอก `docs/SETUP-GUIDE.txt` ไปยังโฟลเดอร์โปรแกรมในชื่อ `SETUP-GUIDE.txt`
2. เมื่อติดตั้งแบบปกติเสร็จ Notepad จะเปิดคู่มือที่ติดตั้งแล้วให้อัตโนมัติ และ Commandblock จะเปิดเหมือนเดิม
3. Start Menu มีทางลัดชื่อ `คู่มือการตั้งค่า Commandblock` เพื่อเปิดคู่มือซ้ำได้สะดวก
4. คู่มือเป็นข้อความภาษาไทยแบบ UTF-8 อธิบายตำแหน่ง `config.json` สำหรับการติดตั้งและแบบพกพา, DeepSeek, Groq, Ollama ในเครื่อง, Ollama Cloud, การเลือกโมเดล และความปลอดภัยของ API key

## การออกแบบทางเทคนิค

- เก็บไฟล์ต้นฉบับไว้ที่ `docs/SETUP-GUIDE.txt` เพื่อให้แก้ไขและติดตามไปพร้อมกับโปรเจกต์ แล้วให้ Inno Setup คัดลอกเข้าโปรแกรม
- เพิ่มทางลัดใน Start Menu ที่เรียก Windows Notepad พร้อมระบุไฟล์คู่มือ จึงไม่ต้องพึ่งการตั้งค่าโปรแกรมเริ่มต้นสำหรับไฟล์ข้อความ
- เพิ่มคำสั่งหลังติดตั้งเพื่อเปิดคู่มือเดียวกันด้วย Notepad โดยใช้ `postinstall`, `nowait` และ `skipifsilent` ให้สอดคล้องกับพฤติกรรมการเปิดแอปปัจจุบัน และไม่เปิดหน้าต่างในกรณีติดตั้งแบบเงียบ
- ทางลัด Commandblock และโฟลเดอร์ทำงาน `%APPDATA%\\Commandblock` เดิมจะไม่เปลี่ยน

## ความปลอดภัยและการตรวจสอบ

- ห้ามนำ `config.json`, session หรือ API key ใด ๆ เข้าไปในตัวติดตั้ง
- เพิ่มการทดสอบป้องกันการถดถอยของเนื้อหาตัวติดตั้งก่อนแก้ไข โดยตรวจว่ามีไฟล์คู่มือ กฎคัดลอก ทางลัด Start Menu และคำสั่งเปิดคู่มือหลังติดตั้ง
- สร้างตัวติดตั้งหลังการทดสอบเพื่อยืนยันว่าไวยากรณ์ Inno Setup ถูกต้องและไฟล์ติดตั้งมีการเปลี่ยนแปลงนี้
