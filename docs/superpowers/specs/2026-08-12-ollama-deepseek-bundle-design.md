# ตัวติดตั้งเต็ม Ollama และ DeepSeek Coder

## เป้าหมาย

สร้างตัวติดตั้ง Commandblock สำหรับ Windows ที่รวม Ollama Runtime และโมเดล `deepseek-coder:1.3b` เพื่อให้ผู้ใช้ใช้งาน AI ในเครื่องได้ทันทีโดยไม่ต้องใช้ API key หรือดาวน์โหลดโมเดลเพิ่ม พร้อมเสนอให้ผู้ใช้เข้าสู่ระบบ Ollama หลังติดตั้งเพื่อใช้โมเดล Cloud ของบัญชีตนเอง

## ขอบเขตของแพ็กเกจ

- รวมไฟล์ Ollama Runtime สำหรับ Windows ที่ตรวจสอบได้จากแหล่งทางการ
- รวมข้อมูลโมเดล Ollama `deepseek-coder:1.3b` ขนาดประมาณ 776 MB
- รวมไฟล์ license/notices ที่จำเป็นของ Ollama และโมเดล
- ตัวติดตั้งมีขนาดโดยประมาณ 0.8–1 GB ขึ้นไป และต้องแจ้งพื้นที่ดิสก์ที่ต้องใช้
- ไม่รวม API key, บัญชี Ollama, token, ประวัติแชต หรือ config ส่วนตัวของผู้ใช้

## ขั้นตอนติดตั้ง

1. Setup ตรวจว่ามี Ollama อยู่แล้วหรือไม่
2. หากไม่มี ให้เรียกตัวติดตั้ง Ollama ที่มากับแพ็กเกจ; หากมีอยู่แล้ว ให้รักษาเวอร์ชันและข้อมูลเดิมไว้
3. Setup วางไฟล์โมเดลลงในตำแหน่ง model store ของ Ollama โดยใช้ `OLLAMA_MODELS` ถ้าผู้ใช้กำหนดไว้ มิฉะนั้นใช้ `%USERPROFILE%\\.ollama\\models`
4. Setup ตรวจว่า Ollama รู้จัก `deepseek-coder:1.3b` แล้วก่อนเปิด Commandblock
5. Setup เปิดคำสั่ง `ollama signin` แบบโต้ตอบเพื่อให้ผู้ใช้เข้าสู่ระบบในเบราว์เซอร์ของตนเอง ผู้ใช้ปิดหรือข้ามขั้นตอนนี้ได้
6. Setup เปิดคู่มือการตั้งค่า และ Commandblock โดยตั้ง `deepseek-coder:1.3b` เป็นโมเดล Ollama ที่เลือกได้ทันที

## ความปลอดภัยและความเข้ากันได้

- ไม่มีการล็อกอินอัตโนมัติหรือฝัง credential; `ollama signin` ทำงานภายใต้บัญชี Windows ของผู้ติดตั้งเท่านั้น
- การติดตั้งไม่เขียนทับ Ollama หรือโมเดลเดิม และไม่ลบข้อมูลเดิมระหว่างถอนการติดตั้ง Commandblock
- ก่อนคัดลอก model payload ให้ตรวจพื้นที่ว่างและหยุดพร้อมข้อความภาษาไทยหากไม่เพียงพอ
- ลงนามไฟล์ Setup ในอนาคตเมื่อมี code-signing certificate; ห้ามเพิ่ม private key หรือรหัสผ่าน certificate เข้าโปรเจกต์

## การตรวจสอบ

- ตรวจ checksum ของไฟล์ bundle ก่อนนำไปใช้สร้าง Setup
- สร้างตัวติดตั้งด้วย Inno Setup และยืนยันว่ามี runtime, model payload และ notices อยู่ใน output
- ทดสอบบนบัญชีผู้ใช้ Windows ที่ไม่มี Ollama: ติดตั้ง, ตรวจ `ollama show deepseek-coder:1.3b`, เปิด Commandblock และลองเลือกโมเดล
- ทดสอบกรณีมี Ollama และโมเดลเดิม: ยืนยันว่าไม่มีการติดตั้งทับและโมเดลยังเลือกได้
