# Preview Tabs Design

## Goal

ให้พื้นที่ Preview ของ CommandBlock เปิดและสลับพรีวิวได้หลายหน้าในแอปเดียว โดยมีหน้าตาเป็นแถบแท็บแบบเบราว์เซอร์

## Scope

- เพิ่มแถบแท็บย่อยเฉพาะใน `pane-preview` เหนือ iframe เดิม
- แต่ละแท็บมีไอคอน ชื่อย่อของหน้า ปุ่มปิด `×` และเก็บ URL ของตัวเอง
- ปุ่ม `+` สร้างแท็บว่างและโฟกัสช่อง URL ใน toolbar
- ผู้ใช้วาง URL HTTPS แล้วกด Enter เพื่อเปิดในแท็บปัจจุบัน
- คำสั่ง `/preview URL` และ `open_preview` เปิดหรืออัปเดตแท็บ Preview ที่กำลังเลือก
- ปุ่ม `เปิดในเบราว์เซอร์` ใช้ URL ของแท็บที่กำลังเลือก
- YouTube และเว็บไซต์ที่ปฏิเสธ iframe จะแสดงข้อความในแท็บนั้น พร้อมปุ่มเปิด URL ในเบราว์เซอร์ แทนการพยายาม bypass นโยบายของเว็บไซต์
- เก็บรายการแท็บและแท็บที่เลือกใน `sessionStorage` ของแอป เพื่อคงไว้เมื่อรีเฟรชหน้าต่างใน session เดียว แต่ไม่ซิงก์ URL ระหว่างบัญชีหรืออุปกรณ์

## Interaction

1. เมื่อ Preview ได้ URL ครั้งแรก จะสร้างแท็บชื่อจาก hostname และเลือกแท็บนั้น
2. แถบแท็บแสดงจากซ้ายไปขวา; แท็บปัจจุบันใช้ม่วงสว่างเล็กน้อยและแท็บอื่นใช้ Obsidian ม่วงเข้ม
3. ปุ่ม `×` ปิดแท็บนั้น; ถ้าปิดแท็บที่เลือก ให้เลือกแท็บติดกันทางซ้าย หรือแท็บที่เหลืออันแรก
4. ถ้าปิดแท็บสุดท้าย ให้แสดง empty state เดิมและกลับไปมีแท็บว่างสำหรับใส่ URL ผ่านปุ่ม `+`
5. ปุ่มรีเฟรชรีเฟรชเฉพาะ iframe ของแท็บที่เลือก
6. บนมือถือ แถบแท็บเลื่อนแนวนอนได้และปุ่ม `+` คงอยู่ด้านขวา โดยไม่เพิ่ม bottom navigation

## Data Model

ใช้ state ใน UI เท่านั้น:

```js
{
  tabs: [{ id: string, url: string, title: string, kind: 'local' | 'https' }],
  activeId: string
}
```

URL local `http://127.0.0.1:*` ยังสร้างจาก backend ผ่าน `open_preview`; URL HTTPS ตรวจสอบโดย backend เช่นเดิมก่อนเข้าสู่ UI state

## Error Handling

- URL ว่างหรือไม่ใช่ HTTPS: แสดง toast และไม่เปลี่ยนแท็บ
- iframe โหลดไม่สำเร็จหรือถูกบล็อก: แสดง fallback ในแท็บพร้อมปุ่มเปิด browser
- การคืนค่า sessionStorage ผิดรูปแบบ: ทิ้งข้อมูลที่ผิดและเริ่ม state ว่างโดยไม่ทำให้หน้าอื่นใช้งานไม่ได้

## Tests

- static contract test ตรวจ DOM ของ tab strip, ปุ่ม `+`, ปุ่มปิด, URL field และฟังก์ชันจัดการแท็บ
- unit test สำหรับสร้าง เลือก ปิด และคืนค่าแท็บจาก sessionStorage
- browser smoke test: สร้างแท็บ วาง URL สลับแท็บ ปิดแท็บ และยืนยันว่า UI ไม่เกิด JavaScript error

## Constraints

- คงธีม Obsidian–ม่วงและไม่เพิ่ม dependency ใหม่
- ไม่ bypass `X-Frame-Options` หรือ Content Security Policy ของเว็บไซต์ภายนอก
- เพิ่ม version ของ EXE เมื่อเผยแพร่ฟีเจอร์
