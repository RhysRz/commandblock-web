คู่มือการตั้งค่าและใช้งาน Commandblock
========================================

Commandblock คือผู้ช่วยพัฒนาโค้ด AI บน Windows ใช้สนทนาเป็นภาษาไทยหรืออังกฤษ
เพื่ออ่านโค้ด อธิบายโปรเจกต์ สร้างหรือแก้ไขไฟล์ รันคำสั่ง และเปิดพรีวิวเว็บ

คู่มือนี้เปิดให้อัตโนมัติหลังติดตั้ง และเปิดอีกครั้งได้จาก Start Menu:
  Start > Commandblock > คู่มือการตั้งค่า Commandblock


1) เริ่มต้นใช้งาน
-----------------

1. เปิด Commandblock จากไอคอนบน Desktop หรือ Start Menu
2. กดปุ่ม “โฟลเดอร์” แล้วเลือกโฟลเดอร์โปรเจกต์ที่ต้องการทำงาน
3. พิมพ์สิ่งที่ต้องการในช่องแชต เช่น

   - “โปรเจกต์นี้คืออะไร สรุปโครงสร้างให้หน่อย”
   - “หาไฟล์ที่จัดการ login แล้วอธิบายให้หน่อย”
   - “สร้างหน้าเว็บ HTML ตัวอย่าง แล้วเปิดพรีวิวให้ดู”
   - “แก้บั๊กนี้ พร้อมบอกไฟล์ที่แก้”

4. กด Enter หรือปุ่มส่งข้อความ แล้วรอให้ AI ตอบและทำงาน

หมายเหตุ: AI อาจขออ่านไฟล์หรือรันคำสั่งเพื่อทำงานให้ครบ ควรตรวจข้อความและ
รายการไฟล์ที่เปลี่ยนก่อนนำไปใช้งานจริง


2) ส่วนต่าง ๆ ของหน้าจอ
------------------------

- ช่องแชต: ใช้สั่งงานและอ่านคำตอบของ AI
- ปุ่มโฟลเดอร์: เลือกโฟลเดอร์โปรเจกต์ที่ AI จะอ่านและแก้ไข
- ปุ่มโมเดลที่แถบสถานะ: สลับ AI model ที่ตั้งไว้ใน config.json
- Queue: ดูลำดับงานและกิจกรรมของเครื่องมือ
- Files: ดูไฟล์ในโปรเจกต์
- Changes: ดูรายการไฟล์ที่ AI สร้างหรือแก้ไข
- Preview: ดูหน้าเว็บที่ AI เปิดพรีวิวให้
- Terminal: รันคำสั่งบนเครื่องของคุณ
- Notes: จดบันทึกงาน

ถ้าข้อความในแชตยาว ให้เลื่อนด้วยล้อเมาส์หรือแถบเลื่อนด้านขวาของพื้นที่แชต


3) ตำแหน่งไฟล์ตั้งค่า
----------------------

หลังติดตั้งแบบ Setup:
  %APPDATA%\Commandblock\config.json

วิธีเปิดเร็ว:
  1. กดปุ่ม Windows + R
  2. วางข้อความนี้ แล้วกด Enter
     %APPDATA%\Commandblock
  3. เปิดไฟล์ config.json ด้วย Notepad

กรณีใช้ไฟล์ Commandblock.exe แบบพกพา (portable):
  config.json จะอยู่ในโฟลเดอร์เดียวกับ Commandblock.exe

ถ้ายังไม่มี config.json ให้เปิด Commandblock หนึ่งครั้ง ระบบจะสร้างไฟล์เริ่มต้น
ให้เอง จากนั้นปิดแอปก่อนแก้ไขไฟล์ และเปิดใหม่เมื่อแก้ไขเสร็จ


4) รูปแบบ config.json
----------------------

ตัวอย่างโครงสร้างพื้นฐาน:

{
  "api_key": "<API_KEY_ของคุณ>",
  "backend": "auto",
  "base_url": "https://api.example.com/v1",
  "model": "ชื่อโมเดล",
  "models": [
    {
      "model": "ชื่อโมเดล",
      "base_url": "https://api.example.com/v1",
      "api_key": "<API_KEY_ของคุณ>"
    }
  ]
}

ความหมายของค่า:

- api_key: กุญแจสำหรับผู้ให้บริการ AI ค่าใน models ของแต่ละโมเดลสามารถใช้ key
  ของตัวเองได้ ถ้าว่างจะใช้ api_key หลัก
- backend: auto, openai, ollama หรือ offline
- base_url: ที่อยู่ API ของผู้ให้บริการ
- model: โมเดลหลักที่เปิดใช้เมื่อเริ่มแอป
- models: รายการโมเดลสำหรับเลือกจากปุ่มโมเดลในแอป

ห้ามใส่ key จริงในคู่มือ เอกสารสาธารณะ ภาพแคปหน้าจอ หรือส่งให้ผู้อื่น


5) ตั้งค่า DeepSeek API
-----------------------

1. สมัครและเติมเครดิตที่ DeepSeek Platform
2. สร้าง API key ในหน้า API Keys
3. เปิด config.json แล้วตั้งค่าตัวอย่างนี้ โดยแทนที่เฉพาะข้อความใน <...>

{
  "api_key": "<DEEPSEEK_API_KEY_ของคุณ>",
  "backend": "openai",
  "base_url": "https://api.deepseek.com",
  "model": "deepseek-v4-flash"
}

4. บันทึกไฟล์ แล้วปิดและเปิด Commandblock ใหม่

หากต้องการเก็บ DeepSeek ร่วมกับโมเดลอื่น ให้เพิ่มเป็นรายการใน models แทนการลบ
รายการเดิม ตัวอย่าง:

{
  "model": "deepseek-v4-flash",
  "models": [
    {
      "model": "deepseek-v4-flash",
      "base_url": "https://api.deepseek.com",
      "api_key": "<DEEPSEEK_API_KEY_ของคุณ>"
    }
  ]
}

ถ้าขึ้น HTTP 401 ให้ตรวจ API key ถ้าขึ้นข้อความเครดิตไม่พอ ให้เติมเครดิตในบัญชี
DeepSeek และตรวจหน้าใช้งาน/ค่าใช้จ่ายของบัญชีอีกครั้ง


6) ตั้งค่า Groq
----------------

1. สร้าง API key จาก Groq Console
2. ตั้งค่าใน config.json ดังนี้

{
  "api_key": "<GROQ_API_KEY_ของคุณ>",
  "backend": "openai",
  "base_url": "https://api.groq.com/openai/v1",
  "model": "llama-3.3-70b-versatile"
}

3. บันทึก แล้วเปิด Commandblock ใหม่

Groq มีข้อจำกัดการใช้งานตามบัญชีและโมเดล หากพบ HTTP 429 ให้รอสักครู่ หรือดู
ข้อจำกัดของบัญชีใน Groq Console


7) ใช้ Ollama ในเครื่อง (ไม่ต้องใช้ API key)
------------------------------------------------

เหมาะสำหรับผู้ที่ต้องการให้โมเดลทำงานบนเครื่องของตนเอง

1. ติดตั้ง Ollama จาก https://ollama.com
2. เปิด Command Prompt หรือ PowerShell แล้วดาวน์โหลดโมเดล เช่น

   ollama pull qwen2.5-coder:3b

3. ตั้งค่า config.json:

{
  "api_key": "",
  "backend": "ollama",
  "base_url": "http://localhost:11434/v1",
  "model": "qwen2.5-coder:3b"
}

4. เปิด Commandblock ใหม่

ตรวจว่ามีโมเดลในเครื่องด้วยคำสั่ง:

  ollama list

หากเชื่อมต่อไม่ได้ ให้เปิด Ollama หรือรันคำสั่ง `ollama serve` แล้วลองใหม่


8) DeepSeek Coder ที่มากับ Setup
---------------------------------

Commandblock-Setup รุ่นเต็มติดตั้ง Ollama และ `deepseek-coder:1.3b` ให้แล้ว
จึงใช้งานโมเดลเขียนโค้ดในเครื่องได้ทันทีโดยไม่ต้องมี API key หรืออินเทอร์เน็ต
หลังจากติดตั้งเสร็จ

1. เปิด Commandblock
2. กดชื่อโมเดลที่แถบสถานะด้านล่าง
3. เลือก `Ollama (ท้องถิ่น) · deepseek-coder:1.3b`

โมเดลนี้ประมวลผลบนเครื่องของคุณ ความเร็วขึ้นกับ CPU, RAM และ GPU ของเครื่อง
หากแอปแจ้งว่าไม่พบ Ollama ให้ปิดและเปิด Commandblock ใหม่หนึ่งครั้งหลัง Setup
ติดตั้ง Ollama เสร็จ

ห้ามลบโฟลเดอร์ `%USERPROFILE%\.ollama\models` หากต้องการเก็บโมเดลไว้ใช้งาน


9) ใช้ Ollama Cloud
-------------------

โมเดลที่ลงท้ายด้วย :cloud ทำงานบน Ollama Cloud ไม่ได้ใช้พลังประมวลผลจากเครื่อง
ทั้งหมด ตัวอย่างโมเดลที่ตั้งไว้ได้คือ:

  glm-5.2:cloud
  minimax-m3:cloud

ขั้นตอน:

1. ติดตั้ง Ollama และเข้าสู่ระบบด้วยคำสั่ง

   ollama signin

2. ใส่โมเดลใน config.json ตัวอย่าง:

{
  "backend": "ollama",
  "base_url": "http://localhost:11434/v1",
  "model": "glm-5.2:cloud",
  "models": [
    { "model": "glm-5.2:cloud", "base_url": "http://localhost:11434/v1" },
    { "model": "minimax-m3:cloud", "base_url": "http://localhost:11434/v1" }
  ]
}

3. เปิด Commandblock ใหม่ แล้วเลือกโมเดลจากปุ่มโมเดลในแถบสถานะ

สิทธิ์ใช้งานและขีดจำกัดของ Ollama Cloud ขึ้นอยู่กับแผนบัญชี Ollama ของคุณ


10) เพิ่มและสลับหลายโมเดล
--------------------------

ตัวอย่างนี้เก็บ Groq, DeepSeek และ Ollama ในเครื่องไว้ด้วยกัน:

{
  "api_key": "<GROQ_API_KEY_ของคุณ>",
  "backend": "auto",
  "base_url": "https://api.groq.com/openai/v1",
  "model": "llama-3.3-70b-versatile",
  "models": [
    {
      "model": "llama-3.3-70b-versatile",
      "base_url": "https://api.groq.com/openai/v1",
      "api_key": "<GROQ_API_KEY_ของคุณ>"
    },
    {
      "model": "deepseek-v4-flash",
      "base_url": "https://api.deepseek.com",
      "api_key": "<DEEPSEEK_API_KEY_ของคุณ>"
    },
    {
      "model": "qwen2.5-coder:3b",
      "base_url": "http://localhost:11434/v1",
      "api_key": ""
    }
  ]
}

บันทึกไฟล์ เปิด Commandblock ใหม่ แล้วกดชื่อโมเดลที่แถบสถานะเพื่อเลือกโมเดล
ที่ต้องการใช้


11) การแก้ปัญหาพื้นฐาน
------------------------

- แอปแจ้ง offline หรือเชื่อม AI ไม่ได้
  ตรวจว่ามี API key ที่ถูกต้อง หรือ Ollama เปิดทำงานอยู่ แล้วเปิดแอปใหม่

- HTTP 401 / unauthorized
  API key ผิด หมดอายุ หรือถูกวางผิดช่อง ตรวจ key ที่ผู้ให้บริการและอย่าเว้นวรรค

- HTTP 429 / rate limit
  ใช้คำขอเร็วเกินโควตา รอสักครู่ หรือตรวจ quota/เครดิตในบัญชีผู้ให้บริการ

- HTTP 403 / subscription required
  โมเดลนั้นต้องใช้สิทธิ์หรือแผนที่รองรับ ให้ตรวจแผนบัญชีของผู้ให้บริการ

- แก้ config.json แล้วไม่มีผล
  ตรวจ JSON ด้วยการดูว่ามี comma และเครื่องหมายปีกกาครบ ปิด Commandblock ทุกหน้าต่าง
  แล้วเปิดใหม่

- เลือกโมเดลไม่ได้
  ตรวจชื่อ model และ base_url ใน models ให้ถูกต้อง สำหรับ Ollama ให้รัน `ollama list`
  เพื่อตรวจชื่อโมเดลจริง


12) Remote PC จาก CommandBlock Web
-----------------------------------

ใช้ดูหน้าจอหรือควบคุม PC ของคุณจาก CommandBlock Web ได้ โดยต้องใช้บัญชีเดียวกัน
และต้องอนุมัติที่เครื่องปลายทางทุกครั้ง

1. เปิด PowerShell ในโฟลเดอร์ที่มี Commandblock.exe
2. รัน:

   Commandblock.exe --remote

3. ลงชื่อเข้าใช้ด้วยอีเมลและรหัสผ่านบัญชี CommandBlock Web
4. กลับไปที่เว็บ แล้วกดปุ่ม “Remote PC” เลือกเครื่องที่ออนไลน์
5. เลือก “ดูหน้าจอ” หรือ “ควบคุมเครื่อง” แล้วกดยืนยันในหน้าต่าง Windows

ภาพหน้าจอและคำสั่งควบคุมเชื่อมตรงแบบ WebRTC (P2P) ไม่บันทึกภาพลง Supabase
Supabase ใช้สำหรับจับคู่การเชื่อมต่อชั่วคราวเท่านั้น หากเครือข่ายบล็อก UDP
การเชื่อมต่อ P2P อาจใช้งานไม่ได้ ให้ลองเปลี่ยนเครือข่าย


13) ความปลอดภัย
----------------

- API key คือรหัสลับที่อาจมีค่าใช้จ่าย ห้ามส่งในแชต โพสต์ หรือภาพหน้าจอ
- อย่าอัปโหลด config.json ที่มี key ไป GitHub หรือส่งให้คนอื่น
- หากเผลอเปิดเผย key ให้เพิกถอน (revoke) key เดิมที่หน้าเว็บผู้ให้บริการ แล้วสร้างใหม่
- ก่อนให้ AI แก้ไขโปรเจกต์สำคัญ ควรสำรองข้อมูลหรือใช้ Git commit ไว้ก่อน
- ตรวจคำสั่งใน Terminal ก่อนอนุญาตให้รัน โดยเฉพาะคำสั่งลบไฟล์ แก้ฐานข้อมูล หรือส่งข้อมูลออกอินเทอร์เน็ต
