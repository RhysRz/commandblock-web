# 🤖 Commandblock — ผู้ช่วยพัฒนาโค้ด AI (ตัวแทนอัจฉริยะในเทอร์มินัล)

**Commandblock** คือผู้ช่วยพัฒนาโค้ดอัจฉริยะแบบ **agentic CLI** — พิมพ์งานเป็นภาษาไทย (หรืออังกฤษ) แล้ว Commandblock
จะคิด วางแผน ใช้เครื่องมือ (อ่าน/แก้ไขไฟล์, ค้นหาโค้ด, รันคำสั่ง) วนไปจนงานเสร็จ
เหมือนผู้ช่วย AI เขียนโค้ดตัวเต็ม (เช่น Codebuff / Claude Code) แต่รันบนเครื่องของคุณเอง
และอยู่ในไฟล์ **`Commandblock.exe`** ไฟล์เดียว — ไม่ต้องติดตั้งอะไรเพิ่ม

| 🧠 Agentic loop | Commandblock เรียกเครื่องมือเองวนไปจนเสร็จงาน พร้อมรายงานความคืบหน้า |
| ⚡ Streaming | ตอบแบบพิมพ์ทีละคำ เหมือนแชท AI จริง (ไม่ต้องรอทั้งก้อน) |
| 🔁 กันกระสุน | รองรับทั้ง tool-call แบบ structured และ JSON fallback + ตรวจจับลูป + retry อัตโนมัติเมื่อ API ติดชั่วคราว (429/5xx) — อ่าน "Please retry in Xs" จาก error แล้วรอตามเวลาจริง (Gemini 20 คำขอ/นาที ไม่ค่อยติด) |

| 🧠 ความจำข้ามเซสชัน | จำบทสนทนาก่อนหน้าได้ (บันทึกใน `buff_session.json` — พิมพ์ `/forget` เพื่อล้าง) |
| 👤 บัญชีผู้ใช้ (Register/Login) | หน้าเข้าสู่ระบบ/สมัครสมาชิกสวยๆ ในแอป — ใช้บัญชีเดียวกับ CommandBlock Web (Supabase Auth) — **ประวัติแชทและโน้ตแยกเก็บต่อบัญชี** (`.freebuff/sessions/<user_id>.json`, `.freebuff/notes_<user_id>.md`) + **ซิงก์ประวัติแชทกับคลาวด์** (ตาราง conversations/messages เดียวกับเว็บ — ใช้ข้ามเครื่องได้) ออกจากระบบได้ใน Project settings |
| 🔄 อัปเดตอัตโนมัติ | ตรวจเวอร์ชันใหม่จาก GitHub Releases ตอนเปิดแอป + แจ้งเตือนใต้ช่องส่ง (ดาวน์โหลด/ติดตั้งเอง พร้อมตรวจ SHA-256) + **ปุ่ม "ตรวจอัปเดตตอนนี้" ใน Project settings** เช็คได้ทันทีไม่ต้องปิดเปิดแอป |
| 🧩 3 แบ็กเอนด์ | Ollama (ท้องถิ่น ไม่ต้องใช้ key) · OpenAI-compatible API · โหมด offline |
| 🎯 เลือกโมเดลอัตโนมัติ | ตรวจโมเดลใน Ollama และเลือกตัวที่เร็วที่สุดให้อัตโนมัติ |
| 🔀 สลับโมเดลในแอป | กดปุ่มโมเดลที่ status bar → เลือกได้ทันที (จาก `models` ใน config.json + โมเดล Ollama ที่ติดตั้ง) ไม่ต้องแก้ไฟล์ |

## 🚀 วิธีใช้งาน

### ใช้งานผ่านเว็บ 🌐

เปิด [Commandblock Web](https://rhysrz.github.io/commandblock-web/) แล้วสมัคร/เข้าสู่ระบบด้วยอีเมล
หน้าเว็บใช้ UI **ชุดเดียวกับแอปเดสก์ท็อป** (หน้าตา 3 คอลัมน์, แถบไอคอน, status bar, แถบโฟลเดอร์ — build จาก `src/ui.html` ตัวเดียวกัน) และมีหน้าเข้าสู่ระบบ/สมัครสมาชิกแบบ glassmorphism เดียวกับ exe (เข้าสู่ระบบด้วยบัญชี Supabase เดียวกัน — เห็นชิปบัญชีใน status bar, ออกจากระบบได้ใน Project settings)
แชทใช้ DeepSeek Cloud ผ่าน API key ของผู้ใช้เอง ซึ่งเก็บใน **localStorage ของเบราว์เซอร์นั้น** (กรอกครั้งแรกผ่านกล่อง 🔑 ในแอป — รองรับมือถือ/webview ที่ `prompt()` ใช้ไม่ได้) ไม่บันทึกลงบัญชีหรือ GitHub

- **สั่งงานเข้าคอมได้จากมือถือ/เว็บ:** แชทเป็น **agentic** — AI วางแผนแล้วใช้เครื่องมือผ่าน **Desktop Connector** (รันคำสั่ง, อ่านไฟล์, ดูรายการไฟล์) วนจนงานเสร็จ ดูกิจกรรมเครื่องมือ (chips ⌨️/📁) ได้แบบเรียลไทม์ ถ้าไม่มี connector ออนไลน์ AI จะรายงานและแนะนำวิธีเปิด
- ใช้แชท, ประวัติสนทนา, การเลือกโมเดล Cloud และโน้ตชั่วคราวในเบราว์เซอร์ได้
- **รองรับมือถือ:** จอ ≤ 900px จะเป็นเลย์เอาต์มือถือ (แชทเต็มจอ + แถบไอคอนด้านล่าง, แผงประวัติ/แท็บเปิดเป็น overlay เลื่อนจากขอบพร้อมปุ่ม ✕ และ backdrop) — ปุ่ม **📂 เลือกโฟลเดอร์** อยู่บนมือถือด้วย (เปิด dialog เลือกโฟลเดอร์บนคอมผ่าน Desktop Connector แล้ว AI อ่านทั้งโฟลเดอร์ได้)
- แท็บ Files, Changes, Preview, Terminal, เลือกโฟลเดอร์, skills และ startup script ต้องใช้แอปเดสก์ท็อปหรือ Desktop Connector เพราะเบราว์เซอร์ไม่ควรเข้าถึงไฟล์และคำสั่งในเครื่องโดยตรง

การ build เว็บใหม่: `node scripts/build-web.mjs` (เอา `src/ui.html` + `web/cloud-adapter.js` มาประกอบเป็น `site/`) — ทดสอบ local ได้ด้วย `python -m http.server 8080` ในโฟลเดอร์ `site/`

### Desktop Connector (ใช้ Files และ Terminal จากเว็บ)

หลัง apply migration `supabase/migrations/202608120002_connector.sql` กับโปรเจกต์ Supabase แล้ว เปิด Command Prompt ในโฟลเดอร์ Commandblock และรัน:

```powershell
Commandblock.exe --connector
```

เข้าสู่ระบบด้วยอีเมลเดียวกับเว็บ แล้วเลือกโฟลเดอร์ที่อนุญาตให้เว็บเข้าถึง โปรแกรมเชื่อมออกผ่าน HTTPS จึงใช้ได้จาก Remote PC โดยไม่ต้องเปิดพอร์ตหรือแก้ Router

### Remote PC (ดูจอ/ควบคุมจากเว็บ)

1. อัปเดต CommandBlock ให้เป็นรุ่นล่าสุด แล้วเปิด PowerShell ในโฟลเดอร์โปรแกรม
2. รัน `Commandblock.exe --remote` แล้วลงชื่อเข้าใช้ด้วยบัญชีเดียวกับ CommandBlock Web
3. ที่เว็บกด `🖥 Remote PC` เลือกเครื่อง แล้วเลือก **ดูหน้าจอ** หรือ **ควบคุมเครื่อง**
4. ยืนยันการอนุญาตในหน้าต่าง Windows ทุกครั้งก่อนเริ่มเชื่อมต่อ

ภาพหน้าจอและคำสั่งควบคุมใช้ WebRTC แบบ peer-to-peer; Supabase ใช้แค่จับคู่การเชื่อมต่อชั่วคราว ไม่ได้เก็บภาพหน้าจอหรือพิมพ์ที่ส่งผ่าน Remote PC. บางเครือข่ายที่บล็อก UDP อาจเชื่อมต่อ P2P ไม่ได้.

- หน้าเว็บเลือก Connector ที่ออนไลน์ล่าสุดให้เอง
- Files, อ่านไฟล์, Queue, Changes และเลือกโฟลเดอร์ทำงานเฉพาะใน root ที่เลือก
- Terminal ทุกคำสั่งต้องพิมพ์ `yes` ยืนยันบนเครื่อง Connector และจำกัดเวลา 60 วินาที
- ปิด Connector หรือกด `Ctrl+C` เพื่อหยุด; session และรหัสผ่านไม่ถูกบันทึกลงดิสก์

### วิธีที่ 1: ดับเบิลคลิก (ง่ายสุด) — เปิดแอปเดสก์ท็อปจริง 🖥️
ดับเบิลคลิกที่ไฟล์ **`start.bat`** → หน้าต่างแอป **"🤖 Commandblock — ผู้ช่วยพัฒนาโค้ด AI"** เปิดขึ้นมา
(ไม่มี console ให้รก) — เลย์เอาต์ 3 แถบเหมือนแอป AI มืออาชีพ:

- **ซ้ายสุด: แถบไอคอน (activity bar)** — สลับแท็บด้วยไอคอน: ☰ Queue · 📁 Files · ⎇ Changes · 🖼️ Preview (จุดเขียว = พรีวิว) · ⌨️ Terminal · 📄 Notes + ปุ่มซ่อน/แสดงประวัติ + ปุ่ม **⚙ Project settings** (ตั้งค่า + เพิ่มสกิล)
- **ซ้าย:** แชท + ปุ่ม `📂 โฟลเดอร์` + ปุ่ม `/preview` + **📎 แนบไฟล์** (เลือกไฟล์หรือ **Ctrl+V วางรูปจากแคปหน้าจอ** — AI เห็นรูปได้แล้ว) + ช่องพิมพ์ + status bar — **กดปุ่มโมเดลเพื่อสลับโมเดลทันที** (รายการจาก `models` ใน config.json + โมเดลใน Ollama ตรวจอัตโนมัติ) พร้อมตัวนับทักษะ/ความจำ
- **📂 เปิดโฟลเดอร์:** กดปุ่ม **📂 โฟลเดอร์** → เปิดกล่องเลือกโฟลเดอร์ **native ของ Windows** (ไม่ใช่ป๊อปอัปเว็บ) → Commandblock อ่านไฟล์ทั้งโฟลเดอร์จากดิสก์โดยตรง (สูงสุด 150 ไฟล์ ไฟล์ละ ~8KB ข้ามไบนารี/โฟลเดอร์ใหญ่) ใส่ลง system prompt ให้เข้าใจโครงสร้าง/เนื้อหาทันที แล้วถามหรือสั่งให้แก้ไฟล์ต่อได้เลย — ถ้าโฟลเดอร์อยู่ในโปรเจกต์ปัจจุบัน Commandblock แก้ไฟล์ด้วยพาธสัมพัทธ์ได้จริง — **ใต้ช่องส่งมีแถบ 📁 ชื่อโฟลเดอร์ปัจจุบัน** (เริ่มจากโฟลเดอร์โปรเจกต์ เปลี่ยนตามที่เลือก — เอาเมาส์ชี้ดูพาธเต็ม)
- **⚙ Project settings (ไอคอนสไลด์ล่างสุดของแถบไอคอน):** หน้าต่างตั้งค่าแบบ Freebuff — **Startup script** (คำสั่ง bash ที่จะรัน**เทิร์นแรกของแต่ละวัน** — จดวันที่รันล่าสุดใน settings.json วันใหม่รันอีกครั้ง ก่อนเริ่มงาน) + **Preloaded skills** (ติ๊กสกิลที่อยากเปิดใช้ → ใส่ SKILL.md ของมันจริงลง system prompt ให้สกิลมีผลทันที ไม่ต้องโหลดเอง) + **Startup script history** (ประวัติผลลัพธ์ย้อนหลังหลายวัน — วัน/เวลา สถานะ ✓/✗ กดขยายดู output เก็บที่ `.freebuff/startup_log.json` สูงสุด 60 รายการ) — บันทึกที่ `.freebuff/settings.json`
- **⏱️ เรียลไทม์แบบ Freebuff:** ตอนทำงานเห็นสดๆ ทุกขั้นตอน — กล่อง **🤔 Thinking** (ความคิดของโมเดล), ไลน์กิจกรรมเครื่องมือ (📖 Read / ✏️ Edit / 🔍 Search...), กล่อง **To-dos** (แผนงานเป็นเช็กลิสต์ ขีดถูกตามความคืบหน้า) + กล่องสรุปไฟล์ที่แก้
- **กลาง:** ประวัติสนทนา (แตะข้อความเก่าเพื่อถามซ้ำได้, ซ่อน/แสดงได้ด้วยปุ่มแถบไอคอน)
- **ขวา:** แท็บ **Terminal** (รันคำสั่งจริง), **Files** (รายการ/อ่านไฟล์), **Changes** (ไฟล์ที่ Commandblock แก้),
  **Preview** (ดูพรีวิวเว็บ), **Queue** (กิจกรรมเครื่องมือ), **Notes** (โน้ต บันทึกที่ notes.md)
- **📦 กล่องสรุปไฟล์ที่แก้ (แบบ Freebuff):** ทุกครั้งที่ Commandblock เขียน/แก้ไขไฟล์ จะมีกล่องในแชท
  "Agent changed N files" พร้อมยอดรวม **+บรรทัด -บรรทัด** และรายการไฟล์ทีละแถว
  (ป้าย **A** เขียว = สร้างใหม่, **M** เหลือง = แก้ไข, พร้อมตัวเลข +N -M ต่อไฟล์) — ดูซ้ำได้ที่แท็บ Changes

## ⚙️ การตั้งค่า AI

Commandblock ใช้ไฟล์ **`config.json`** (สร้างให้อัตโนมัติครั้งแรกที่รัน อยู่ในโฟลเดอร์ที่รัน Commandblock)
หรือใช้ตัวแปร env (env ชนะ config):

| ตัวแปร | ความหมาย |
|---|---|
| `BUFF_BACKEND` | `auto` (default) · `openai` · `ollama` · `offline` |
| `BUFF_API_KEY` | API key สำหรับ OpenAI-compatible API (หรือใช้ `OPENAI_API_KEY`) |
| `BUFF_BASE_URL` | เช่น `https://api.openai.com/v1` หรือ `http://localhost:11434/v1` |
| `BUFF_MODEL` | ชื่อโมเดล เช่น `qwen2.5-coder:3b`, `gpt-4o-mini` |

### แบ็กเอนด์ A: Ollama (ท้องถิ่น — เครื่องนี้ใช้อยู่)
```bash
# ติดตั้ง Ollama: https://ollama.com แล้วรันคำสั่งนี้ (ถ้ายังไม่มีโมเดล)
ollama pull qwen2.5-coder:3b
```
Commandblock ตรวจพบ Ollama + เลือกโมเดลสาย coder ตัวเร็วสุดให้อัตโนมัติ
ถ้าอยากใช้ตัวฉลาดขึ้น (ช้าลง): แก้ `config.json` → `"model": "qwen2.5-coder:14b"`

### แบ็กเอนด์ B: API แบบ OpenAI-compatible (ฉลาดสุด)
แก้ `config.json`:
```json
{
  "backend": "auto",
  "base_url": "https://api.openai.com/v1",
  "api_key": "sk-...",
  "model": "gpt-4o-mini"
}
```
ใช้กับ OpenAI / DeepSeek (`https://api.deepseek.com/v1`) / Gemini / อื่นๆ ที่รองรับ
รูปแบบ `/v1/chat/completions` + function calling

### แบ็กเอนด์ B2: โมเดลฟรีผ่าน OpenRouter ⭐ (ไม่เสียเงิน)

> หมายเหตุ: DeepSeek V4 Flash **ไม่มีเวอร์ชันฟรีอีกต่อไป** (รันในเครื่องไม่ได้เพราะ 284B ต้องใช้แรม ~100GB, `:cloud` ต้องเสีย subscription, `:free` บน OpenRouter ถูกยกเลิก)

ใช้โมเดลฟรีอื่นแทน (มี ~14 ตัว เช่น `cohere/north-mini-code:free` — ตัวที่ Commandblock ใช้อยู่ตอนนี้):

1. สมัครบัญชีฟรีที่ https://openrouter.ai แล้วสร้าง API key (ฟรี ไม่ต้องใช้บัตรเครดิต)
2. ใส่ key ใน `config.json` → ช่อง `api_key` (ค่าอื่นๆ ตั้งไว้ให้แล้ว):
   ```json
   { "backend": "auto", "base_url": "https://openrouter.ai/api/v1", "api_key": "sk-or-...", "model": "cohere/north-mini-code:free" }
   ```
3. ดูโมเดลฟรีทั้งหมดได้ที่: https://openrouter.ai/models?max_price=0

ถ้าอยากได้ **DeepSeek V4 Flash จริงๆ** (ฉลาดสุด): ใช้ API ทางการของ DeepSeek โดยเติมเงินขั้นต่ำ
(ราคาถูกมาก ~$0.14/1M input): `base_url: "https://api.deepseek.com"` + `model: "deepseek-v4-flash"`

> ⚠️ **ขีดจำกัด OpenRouter ฟรี:** โควตาฟรีของบัญชี OpenRouter คือ **50 คำขอ/วัน รวมทุกโมเดล :free**
> (เจอ `HTTP 429 free-models-per-day` = หมดแล้ว รีเซ็ตเที่ยงคืน UTC = 07:00 น. เวลาไทย)

### แบ็กเอนด์ B3: โมเดลฟรีที่ไม่ติดโควตาร่วมกัน ⭐ (แนะนำตอน OpenRouter หมดโควตา)
มีโมเดลฟรีของ provider อื่นที่ **มี key คนละตัว ไม่นับรวมกับโควตา OpenRouter** — ตั้งไว้ใน `config.json` แล้ว (ใส่ key ในช่อง `api_key` ของแต่ละตัว):

| โมเดล | ได้ key ที่ไหน (ฟรี) | ข้อดี |
|---|---|---|
| **Gemini 2.5 Flash** (`gemini-2.5-flash`) | https://aistudio.google.com → Get API key (ล็อกอิน Google) | ฉลาดมาก, ~1,000+ คำขอ/วัน ฟรี |
| **Groq Llama 3.3 70B** (`llama-3.3-70b-versatile`) | https://console.groq.com/keys | เร็วมาก ใช้งานได้จริง |
| Ollama ในเครื่อง | ไม่ต้องใช้ key | ไม่จำกัด แต่ช้า (ตาม CPU) |

```json
{
  "model": "gemini-2.5-flash",
  "models": [
    { "model": "gemini-2.5-flash", "base_url": "https://generativelanguage.googleapis.com/v1beta/openai", "api_key": "AIza..." },
    { "model": "llama-3.3-70b-versatile", "base_url": "https://api.groq.com/openai/v1", "api_key": "gsk_..." }
  ]
}
```
เมื่อใส่ key แล้ว กด **ปุ่มโมเดลใน status bar** → เลือกได้ทันที (Commandblock ใช้ key ของแต่ละโมเดลเอง)

### 🔀 สลับโมเดลในแอป (ไม่ต้องแก้ไฟล์)
ใส่รายการโมเดลใน `config.json` → ช่อง `models` (รับ string, `{model, base_url}`, หรือ `{model, base_url, api_key}` สำหรับ key ต่อโมเดล):
```json
{
  "model": "cohere/north-mini-code:free",
  "models": [
    { "model": "cohere/north-mini-code:free", "base_url": "https://openrouter.ai/api/v1" },
    { "model": "deepseek-v4-flash", "base_url": "https://api.deepseek.com" },
    "qwen2.5-coder:3b"
  ]
}
```
แล้วกด **ปุ่มโมเดลที่ status bar** ในแอป → เลือกโมเดลที่ต้องการ ใช้ทันที
(โมเดลใน Ollama ที่ติดตั้งไว้จะถูกเพิ่มให้อัตโนมัติด้วย)

### แบ็กเอนด์ C: offline
ไม่มี key และไม่มี Ollama → Commandblock จะบอกวิธีตั้งค่าให้

---

## 🧠 ความจำข้ามเซสชัน

Commandblock จำบทสนทนาก่อนหน้าได้ — พิมพ์งานทิ้งไว้แล้วปิดโปรแกรม เปิดใหม่มาถามต่อได้เลย
(บันทึกอัตโนมัติในไฟล์ `buff_session.json` ข้าง Commandblock.exe)

- ปิด/เปิดใหม่ → Commandblock ขึ้นข้อความ "🧠 จำบทสนทนาก่อนหน้าได้ N ข้อความ"
- ล้างความจำ: พิมพ์ `/forget` (ลบไฟล์ session)
- ใช้ได้ทั้งโหมดแชทและ one-shot

## 🌐 ค้นหาข้อมูลในอินเทอร์เน็ต

Commandblock ใช้ `web_search` (ค้นผ่าน DuckDuckGo — ฟรี ไม่ต้องใช้ key) และ `read_url` (อ่านหน้าเว็บ)
เพื่อหาข้อมูลปัจจุบันที่ไม่อยู่ในโปรเจกต์ เช่น:

```
คุณ> Rust เวอร์ชันล่าสุดคืออะไร
คุณ> ค้นหาวิธีตั้งค่า Docker บน Windows แล้วสรุปขั้นตอนให้หน่อย
คุณ> อ่าน https://docs.rs/serde/latest/serde/ แล้วบอกว่าใช้งานยังไง
```

## 🔁 ถ้า API ติดชั่วคราว

Commandblock ลองส่งใหม่ให้อัตโนมัติ (สูงสุด 3 ครั้ง) เมื่อเจอ HTTP 429 / 5xx หรือเน็ตหลุด —
สำคัญมากสำหรับโมเดลฟรีบน OpenRouter ที่จำกัดอัตราการเรียก

## 🖥️ พรีวิวเว็บแบบเห็นภาพ

บอก Commandblock ว่า "สร้างหน้าเว็บแล้วเปิดพรีวิวให้ดูหน่อย" — Commandblock จะสร้าง HTML แล้วใช้
`open_preview` เปิดในเบราว์เซอร์ของคุณทันที:

```
คุณ> สร้างหน้าเว็บโปรไฟล์สวยๆ แล้วเปิดพรีวิวให้ดู
คุณ> ทำเว็บแอปนับเลข แล้วเปิดพรีวิว
```

- เซิร์ฟเวอร์รันที่ `http://127.0.0.1:พอร์ต` จนกว่าจะปิด Commandblock (พิมพ์ `/preview` เพื่อเปิดซ้ำ)
- โหมด one-shot: Commandblock จะค้างไว้ให้ดูจนกว่าจะกด Enter / Ctrl+C

## 📚 ทักษะเฉพาะทาง (skills)

Commandblock โหลดทักษะ (SKILL.md) มาปฏิบัติตามได้เหมือนผู้ช่วย AI ระดับมืออาชีพ —
ค้นหาได้จาก 3 ที่ (เรียงตามลำดับ): `BUFF_SKILLS_DIR` → `./skills` ในโปรเจกต์ →
`~/.buff/skills` → `~/.agents/skills` (โฟลเดอร์เดียวกับที่ Buffy ใช้)

```
คุณ> /skills                                # ดูรายการทักษะที่มี
คุณ> ตรวจสอบความเข้าถึงของหน้าเว็บนี้หน่อย  # Commandblock จะโหลดทักษะ accessibility ให้เอง
```

สร้างทักษะเองง่ายๆ: สร้างโฟลเดอร์ `skills/<ชื่อ>/SKILL.md` ในโปรเจกต์ แล้วเขียน
frontmatter ขึ้นต้นด้วย `---` + `name:` + `description:` ตามด้วยเนื้อหาคำแนะนำ

## ⚠️ ข้อควรรู้

- **ความเร็ว**: ถ้ารันโมเดลในเครื่อง (CPU) Commandblock จะทำงานช้า ขึ้นกับสเปคเครื่อง —
  ใช้โมเดลเล็ก (3b) เพื่อความเร็ว หรือเชื่อม API cloud เพื่อความฉลาด+เร็ว
- **ความปลอดภัย**: Commandblock รันคำสั่งบนเครื่องของคุณจริงๆ — สั่งงานด้วยความระมัดระวัง
  (Commandblock ถูกสอนให้ถามก่อนถ้าจะรันคำสั่งอันตราย เช่น ลบไฟล์ / git push)
- โหมด offline ไม่ได้ใช้ AI — ต้องตั้งค่าแบ็กเอนด์ก่อน (ดูหัวข้อการตั้งค่า)
