# Performance

1. Measure a baseline before optimizing; identify the slowest user-visible path.
2. Use profiling, tracing, browser tools, query plans, or build timing rather than assumptions.
3. Optimize the confirmed bottleneck with the smallest change.
4. Re-measure against the same workload and check behavior remains correct.
5. Report before/after metrics and tradeoffs such as memory, latency, or complexity.
