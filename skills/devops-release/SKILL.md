# DevOps Release

1. Inspect workflow triggers, build inputs, version identifiers, and required artifacts.
2. Build from a clean, reproducible source state and verify generated packages contain required files.
3. Publish only after checksums, upload state, and release metadata are complete.
4. Make automatic updaters offer a release only when its package is downloadable and verified.
5. Capture CI logs and artifact hashes when diagnosing release failures.
