# Web UI

1. Inspect the existing design system, responsive breakpoints, and component patterns.
2. Build semantic markup, keyboard-safe interactions, readable contrast, and responsive layouts.
3. Keep visual changes consistent with the product's typography, spacing, and state feedback.
4. Test desktop and mobile widths, empty/loading/error states, and keyboard navigation.
5. Use browser inspection or screenshots when visual verification is material.
