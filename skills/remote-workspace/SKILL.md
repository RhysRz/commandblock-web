# Remote Workspace

1. Confirm the Desktop Connector is online and the requested folder is within the granted workspace.
2. Inspect files and command intent before making changes; show concise results back to the user.
3. Use safe relative paths and do not access files outside the selected root.
4. Ask before destructive commands, credential changes, external publishing, or broad system actions.
5. For Remote PC, require the one-time approval flow and state clearly when P2P connectivity or screen sharing is unavailable.
