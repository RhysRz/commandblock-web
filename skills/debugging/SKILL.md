# Debugging

1. Capture the exact error, steps to reproduce, environment, and recent changes.
2. Trace the failing data backward through each component boundary; add safe diagnostics if evidence is missing.
3. Compare a working path with the failing path and state one testable root-cause hypothesis.
4. Add a regression test, apply one focused fix, and rerun the reproduction.
5. Report the root cause, fix, validation, and any remaining environment limitation.
